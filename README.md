# 📸 SortPhoto

### 🛠 Сборка и запуск
Проект максимально автономен: все необходимые зависимости (библиотека Exiv2 для компилятора MinGW) уже включены в репозиторий. Вам не нужно скачивать их отдельно.

**Требования:**
1. Qt 5.15+ / 6.x
2. Компилятор: MinGW (версия, соответствующая вашей сборке Qt).

**📦 Управление зависимостями**
Проект настроен так, чтобы быть независимым от абсолютных путей в системе (Self-contained project).
- Автономность: Библиотека Exiv2 уже включена в состав репозитория.
- Автоматизация: В файле .pro прописаны правила (Deployment steps), которые автоматически копируют необходимые бинарные файлы библиотеки в папку сборки (build/).
- Совместимость: Данная конфигурация гарантированно работает «из коробки» с компилятором MinGW (через который велась линковка в MSYS2).
> [!IMPORTANT]
> При использовании компилятора MSVC автоматическое копирование сработает, но возникнет ошибка линковки из-за несовместимости форматов библиотек. В этом случае потребуется заменить файлы в папке lib/ на версии, скомпилированные под MSVC.

**Инструкция:**
1. Откройте файл SortPhoto.pro в Qt Creator
2. Убедитесь, что выбран комплект (Kit) с компилятором MinGW.
3. Нажмите Alt + Shift + B (Rebuild All) или просто кнопку запуска.
4. После запуска утилиты Вы выберите нужные каталоги и нажмите на кнопку "Начать сортировку".
> [!NOTE]
> Во время сортировки фотографий Вы можете приостановить ее или прервать полностью при необходимости. Помимо этого Вы можете набоюдать за процессом, а именно следит за прогрессом работы программы (ProgressBar), а также просмотреть логи программы, которые выводятся в основном окне.
