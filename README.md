# 📸 SortPhoto

Программа для автоматической сортировки фотографий по папкам на основе даты их создания или изменения.

### 🛠 Стек технологий
* **Framework:** Qt Creator (C++)
* **Libraries:** [Exiv2](https://exiv2.org/) (для работы с метаданными)
